# iPhone 蓝牙信号实测工具

用来回答一个问题：**在你的房间里，用 iPhone 的蓝牙信号强度判断"人在不在电脑前"到底靠不靠谱。**
同一个脚本 Windows 和 macOS 都能跑。手机上不用装 App，测的是 iPhone 平时就会发出的蓝牙广播。

## 安装

需要 Python 3.9 或更高版本。

**Windows**

```
pip install bleak
```

**macOS**

```
python3 -m venv .venv
source .venv/bin/activate
pip install bleak
```

macOS 第一次运行时会弹出蓝牙权限请求，要允许。如果没弹，去「系统设置 → 隐私与安全性 → 蓝牙」里给终端打开。Mac 和 iPhone 要登录同一个 Apple ID，这样 Mac 才能认出你的 iPhone。

## 三个命令

```
python rssi_probe.py scan        # 扫描附近设备，找出你的 iPhone
python rssi_probe.py record      # 记录信号，按数字键标记手机现在在哪
python rssi_probe.py analyze 文件.csv   # 分析记录
```

### 1. scan：找到你的 iPhone

把 iPhone 解锁亮屏，放在电脑旁边，运行 `scan`。信号最强、消息类型里带「附近信息」的 Apple 设备，通常就是你的 iPhone。注意别和旁边的 Mac 搞混：可以把 iPhone 拿远一点再扫一次，信号明显变弱的那个就是它。

在 Windows 上，「地址类型」这一列值得留意：
- **随机**：Windows 没认出这台 iPhone，只能靠工具去跟踪它定期更换的地址。
- **公开**：Windows 已经认出了它的真实地址。

可以先不配对扫一次，再在 Windows 蓝牙设置里配对 iPhone 后扫一次，对比一下。这决定了以后正式软件在 Windows 上能不能免装 App。

### 2. record：按位置测量

```
python rssi_probe.py record
```

开始后有 6 秒自动选目标：把 iPhone 解锁亮屏、贴近电脑。选好之后让手机恢复平时的状态（锁屏），测的就是平时的信号。

然后按数字键切换标签，**不用按回车**：

| 键 | 标签 | 类别 | 怎么测 |
|---|---|---|---|
| 1 | 桌上 | 近 | 手机放桌上，人坐着正常用电脑 |
| 2 | 兜里 | 近 | 手机放裤兜，人坐着。**这一项最关键**，人体会挡信号 |
| 3 | 1米 | 中间 | 站在离电脑 1 米处 |
| 4 | 3米 | 远 | 3 米外 |
| 5 | 门口 | 远 | 房间门口 |
| 6 | 隔壁 | 远 | 隔壁房间，把门关上 |
| 7 | 日常 | 混合 | 正常活动 5 到 10 分钟：走开、回来、坐下，最后对一下模拟结果 |
| 0 | 暂停 | | 这段时间不计入分析 |
| q | 结束 | | |

**每一项的流程**：在电脑前按下标签键 → 带着手机走到对应位置 → 待 90 秒左右 → 回到电脑前按下一个键。
每段开头和结尾各 10 秒会被自动去掉，所以走过去、走回来的时间不影响结果。

记录时屏幕上会实时显示信号强度和模拟状态（靠近 / 离开）。这里用的是默认阈值，只供参考，准确的阈值看 analyze 的结果。

自定义标签用 `--labels`，格式是 `名称:类别`，类别为 near / far / mid / mix：

```
python rssi_probe.py record --labels "桌上:near,兜里:near,沙发:far,厨房:far"
```

### 3. analyze：看结果

```
python rssi_probe.py analyze rssi_20261019_203000_win32.csv
```

输出包括：
- **各位置信号**：中位数、波动范围、每秒收到几个包、最长多久没收到包
- **远近能不能分开**：「近」的低位和「远」的高位有没有重叠，以及建议阈值
- **模拟**：用建议阈值把整段记录重放一遍，看会不会误锁、误判靠近，离开后多久锁屏
- **状态变化时间线**：可以对照你记得的离开、回来时间

想试别的参数：

```
python rssi_probe.py analyze 文件.csv --near-th -62 --far-th -75 --t-far 15 --window 5
```

## 一些说明

- iPhone 会不定期更换蓝牙随机地址，record 会自动跟到新地址上，屏幕上会提示「目标换了地址」。
  - 如果 iPhone 广播里带名字（scan 的「名称」列有值），只按名字跟，基本不会跟错。
  - 没有名字时只能靠"旧地址消失后出现的新地址"去猜，可能跟错。出现「切回」就说明刚才误跟了别的设备。
- 周围其他发「附近信息」的设备也会记进 CSV（event 为 other），事后可以查有没有跟丢。
- Windows 会把同一次广播拆成两条上报，工具会自动合并，「包/秒」是真实的广播次数。
- 蓝牙键盘、鼠标和 Wi-Fi 都在 2.4GHz，可能会让每秒收到的包变少。
- Windows 和 Mac 的蓝牙芯片和天线不一样，两台电脑最好各测一次。
- 结果可以直接贴给 Claude，或者把 CSV 发过去，让它帮忙画图分析。
